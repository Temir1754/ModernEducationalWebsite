# Исправление ошибки 413 Request Entity Too Large

Эта ошибка возникает, когда Nginx (или другой прокси-сервер) ограничивает размер загружаемых файлов. По умолчанию в Nginx этот лимит составляет 1 МБ.

## Решение для Nginx

Вам необходимо увеличить значение `client_max_body_size` в конфигурационном файле Nginx (обычно это `/etc/nginx/nginx.conf` или файл вашего сайта в `/etc/nginx/sites-available/`).

1. Откройте конфигурационный файл Nginx.
2. Найдите блок `http`, `server` или `location /`.
3. Добавьте или измените следующую строку:

```nginx
client_max_body_size 500M;
```

4. Сохраните файл и проверьте конфигурацию:

```bash
sudo nginx -t
```

5. Перезапустите Nginx:

```bash
sudo systemctl restart nginx
```

## Для Replit или других платформ

Если вы используете платформу с собственным прокси, убедитесь, что она поддерживает загрузку больших файлов. В коде сервера лимит уже установлен на 500 МБ.
