# Инструкция по обновлению и миграции на сервере

Следуйте этим шагам после входа на сервер через PuTTY:

### 1. Обновление кода
```bash
git pull origin main
```

### 2. Установка зависимостей (если изменились)
```bash
npm install
```

### 3. Загрузка документов и картинок
Так как файлы (`uploads/`, `attached_assets/`, `client/public/gallery/`) игнорируются Git, вам нужно загрузить их на сервер вручную (например, через WinSCP или SFTP) в соответствующие папки в корне проекта.

### 4. Миграция документов в базу данных SQLite
Этот скрипт перенесет записи о документах из текстового файла в `sqlite.db`:
```bash
npx tsx migrate-documents-data.ts
```

### 5. Перезапуск приложения
Если вы используете **PM2**:
```bash
pm2 restart all
```
Или просто перезапустите серверный процесс.

---
**Примечание**: Файл `sqlite.db` был отправлен в репозиторий с актуальными локальными данными (включая исправленные пути к галерее).
